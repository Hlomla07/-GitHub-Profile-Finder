# GitHub Profile Finder 

**Author:** Hlomla Mvinjelwa  
**Email:** hlomlamvinjelwa007@gmail.com
**Live Demo:** https://stellular-maamoul-3e1b87.netlify.app/

## Description
This is an API-based web application that allows users to search for any GitHub profile and view detailed information.  
It was built as part of Week 4 (Advanced JavaScript & API Integration) of the Frontend Development Internship.

## Features
- Search for any GitHub user by username
- Display profile picture, name, bio, location
- Show followers, following, and public repositories count
- Loading spinner while fetching data
- Error handling (user not found, network errors, etc.)
- Fully responsive design
- Clean and modern user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- GitHub Public API

## JavaScript Concepts Applied
- Fetch API

- DOM Manipulation

- Error Handling

## API Used
- **GitHub Users API**: `https://api.github.com/users/{username}`  
  Documentation: [https://docs.github.com/en/rest/users](https://docs.github.com/en/rest/users)

## How to Run
1. Download the project files.
2. Make sure you have these files in the same folder:
   - `index.html`
   - `style.css`
   - `script.js`
3. Open `index.html` in any modern browser.
4. Enter a GitHub username (example: `octocat` or `torvalds`) and click Search.
